# ELADMIN-WEB

#### Frontend Template

Initial template based on: [https://github.com/PanJiaChen/vue-element-admin](https://github.com/PanJiaChen/vue-element-admin)

Template Documentation: [https://panjiachen.github.io/vue-element-admin-site/zh/guide/](https://panjiachen.github.io/vue-element-admin-site/zh/guide/)

#### Build Setup
**Recommended Node.js version: 12+**
``` bash
# Configure npm registry mirror
https://www.ydyno.com/archives/1219.html

# Install dependencies
npm install

# Start dev server localhost:8013
npm run dev

# Build for production
npm run build:prod
```

#### Frequently Asked Questions (FAQ)

1. Issues installing node-sass on Linux systems during dependency installation

Solutions:
```
1. Install separately: npm install --unsafe-perm node-sass 
2. Run directly: npm install --unsafe-perm
```

2. Speeding up node-sass installation

https://izlzl.com/archives/1219.html

3. Error: npm ERR! ModuleNotFoundError: No module named 'distutils'

```
Python and pip (or pip3) must be installed.
Then run: pip install distutils / pip3 install distutils
```
